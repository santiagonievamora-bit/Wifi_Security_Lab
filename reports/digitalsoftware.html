Informe de auditoría WiFi: DigitalSoft

Estado: ficha OSINT completada; captura de handshake documentada.

Alcance: DigitalSoft es una empresa ficticia. La evaluación se limita al AP, cliente y captura autorizados del laboratorio.

1. Resumen ejecutivo

Se documenta una evaluación externa y autorizada de una red WiFi ficticia de DigitalSoft. El objetivo es registrar la captura de un handshake a partir de los datos confirmados de la empresa: desarrollo de software a medida, Enzo Gómez, Salta, Landing Page, Doki, la fecha 02/11 y la publicación de 2022.

2. Objetivos

  • Definir el AP, cliente y canal autorizados.
  • Capturar un handshake por reconexión manual del cliente propio.
  • Documentar el procedimiento y las evidencias de captura sin probar sistemas ajenos.

3. Metodología OWISAM y alcance

Se toma OWISAM, Open Wireless Security Assessment Methodology, como referencia para reconocimiento, identificación, captura controlada y validación de autenticación inalámbrica. Referencia: owisam.org. El pentesting es externo de caja negra: el evaluador no dispone de administración del AP y solo utiliza el perímetro radioeléctrico del laboratorio.

4. Ficha empresarial

Parámetros de captura: BSSID del AP 8E:75:F8:BA:9F:9E; MAC del cliente propio B2:58:73:0C:D6:41. La plataforma y la interfaz inalámbrica están documentadas en hardware_software-laboratorio.md.

5. Procedimiento reproducible

6.1 Reconocimiento

sudo airodump-ng wlan1mon

Seleccionar únicamente el AP preparado para DigitalSoft: BSSID 8E:75:F8:BA:9F:9E y cliente propio B2:58:73:0C:D6:41.

6.2 Captura

Con sudo airodump-ng -c 1 --bssid 8E:75:F8:BA:9F:9E wlan1 -w pruebared corriendo, en otra ventana de la terminal se desautentica al cliente con sudo aireplay-ng -0 9 -a 8E:75:F8:BA:9F:9E -c B2:58:73:0C:D6:41 wlan1.

La captura se registra en pruebared-01.cap y se debe verificar la aparición de WPA handshake antes de detener el proceso.

Captura asignada: handshake-jorge.cap, con SSID DigitalSoft. Conservar el archivo fuera de Git y registrar la aparición del mensaje WPA handshake.
